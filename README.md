# Fastcampus Domain Agent Practices

패스트캠퍼스 **「도메인 AI의 모든 것」** 강의 실습 자료입니다. 단어 임베딩에서 시작해 사전학습 언어 모델, RAG, 단일·멀티 에이전트, 가드레일, 통합 금융 리서치 시스템까지 단계적으로 학습합니다.

강의 이후 발견된 오류를 바로잡거나 학습 설명을 보강하므로 영상 속 코드와 일부 다를 수 있습니다.

실습 전에 [전체 흐름 안내 PPT](fastcampus_도메인_AI_실습_전체흐름.pptx)를 먼저 보면 8개 노트북의 연결 구조를 빠르게 파악할 수 있습니다.

## 실습하는 방법

1. 저장소를 내려받아 Google Colab에 노트북을 올리거나 로컬 Jupyter 환경에서 엽니다.
2. 각 노트북의 **실습을 시작하기 전에** 섹션에서 준비물과 선택 셀을 확인합니다.
3. 셀은 위에서 아래로 실행합니다. 오류가 나면 바로 다음 셀로 넘어가지 말고 현재 셀의 체크포인트부터 확인합니다.
4. 실행 결과를 본 뒤 각 절의 질문에 먼저 답하고, 마지막 선택 과제로 설정값을 하나씩 바꾸어 봅니다.

### 권장 환경

- Python 3.10 이상
- Google Colab 또는 JupyterLab
- 모델 다운로드를 위한 네트워크 연결과 충분한 디스크 공간
- GPU는 일부 심화 셀의 속도를 높이지만 필수는 아닙니다.

각 노트북의 설치 셀을 기준으로 필요한 패키지를 설치합니다. 라이브러리 버전에 따라 런타임 재시작이 필요할 수 있습니다.

## API 키와 비용 주의

- API 키는 코드에 직접 적거나 Git에 커밋하지 마세요. 환경변수나 Colab Secrets를 사용합니다.
- OpenAI API, 모델 다운로드, 외부 검색을 사용하는 셀은 비용·속도·결과가 실행 시점에 따라 달라질 수 있습니다.
- 키가 필요한 선택 셀은 건너뛰어도 앞부분의 핵심 개념을 학습할 수 있도록 구성했습니다.
- 금융 예제의 출력은 교육용이며 투자 조언이 아닙니다. 실제 의사결정 전에 출처와 시점을 별도로 검증하세요.

## 막혔을 때 확인할 것

- `NameError`: 앞 셀을 실행했는지, 런타임이 재시작되지 않았는지 확인합니다.
- `ModuleNotFoundError`: 설치 셀을 실행한 뒤 런타임을 재시작합니다.
- 모델 다운로드 오류: 네트워크, 모델 ID, 접근 권한, 남은 디스크 공간을 확인합니다.
- API 인증 오류: 키가 현재 커널의 환경변수에 설정되었는지 확인합니다.
- 메모리 부족: 샘플 수, 배치 크기, 후보 수를 줄이고 선택 심화 셀은 건너뜁니다.
